# Interview

Settle open decisions with the user before work starts.

1. List the open decisions. Drop any the codebase, docs or the user's request already answer; look those up instead of asking.
2. Ask one question at a time, most blocking decision first. Each question carries your recommended answer and a one-line reason. Wait for the reply before asking the next.
3. A later answer can reopen or remove earlier decisions; re-list after each reply.
4. Never guess a user-owned decision and never batch questions.
5. When none remain, restate the settled decisions in a short list and ask the user to confirm.

Done when: every decision has an explicit answer and the user confirmed the list.
