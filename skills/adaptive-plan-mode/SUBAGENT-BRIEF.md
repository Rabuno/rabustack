# Sub-Agent Brief Template

Disclosed reference for [`adaptive-plan-mode`](SKILL.md) Phase 2. Open when delegating investigation to a sub-agent.

> Goal: \<single sentence\>
>
> Return:
> 1. Key findings with evidence
> 2. Contradictions or surprises
> 3. Unknowns or risks
>
> Constraints:
> - read-only: report findings, don't touch files
> - stay concise

Sub-agent output is evidence, not truth — cross-check critical conclusions.
